{# @description The control that stops and restarts a marquee. A marquee draws its own. A block with several rows draws one of these for all of them. #} {# @prop label:text | description:"The control's name, for a screen reader. Say what is moving. Left empty, it is a translated Pause the movement." #} {# @prop class:text | description:"Extra classes on the control" #} {% comment %} A checkbox, so it holds its state with no script, and the rows read it with `:has()`. Anything that moves for longer than five seconds beside other content needs a way to stop it (WCAG 2.2.2), and stopping under the pointer is no use to a keyboard or a touch screen. It is not drawn under reduced motion, where nothing moves. {% endcomment %} {% load i18n %}
