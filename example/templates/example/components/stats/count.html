Scroll the page. Each figure counts up from nothing the first time it comes into view, and keeps its number from then on. Scrolling only starts the count. From there it runs on the clock, so the number never rests on a figure that is not true.

It needs no script. In a browser without scroll-driven animation, and for anyone who has asked their system to reduce motion, the finished number is simply there. A screen reader is always given the finished number.

A stats row is a scrolling box of its own, and the browser measures "in view" against the nearest one. In there the figures are always in view, so they count once as the page loads and not as you reach them. Reload the page with this row on screen to see it. For a count that waits, put the figures in a plain grid, or in c-stats.band.
