A layout, and nothing behind it. What goes in it is daisy-cotton's own buttons, cards, fields and steps, with the few pieces daisy-cotton has no answer for listed under Page parts in the sidebar. A page is put together from components and not copied as markup. Only the form is a stand-in: in a project it comes from the application, and with django-allauth each slot has an obvious thing to hold:

  • logo takes the application's own logo: an image or inline SVG, usually inside a link home.
  • The default slot takes the form allauth hands the template, with its CSRF token, its redirect field and its errors.
  • providers takes one full-width button for each third-party provider, and one each for the passkey and sign-in code links when those are switched on.
  • footer and nav take the link across to the other page, and the terms.
